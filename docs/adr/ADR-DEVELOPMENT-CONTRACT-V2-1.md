# ADR: Development presentation contract 2.1

Статус: `ACCEPTED`

## Контекст

Текущая модель новостроек использует явные статусы доступности и цены.
Изменение затрагивает замороженный presentation contract между Payload Gateway
и UI, поэтому lock нельзя обновлять без явного решения и новой версии.

## Решение

- повысить версию base contract с `2.0.0` до `2.1.0`;
- заменить `availability` на обязательные `salesStatus` и
  `salesAvailability`;
- добавить `completenessScore`;
- заменить `priceRows` на `priceByRooms` с диапазоном цены, количеством лотов
  и датой проверки;
- добавить типизированные `mediaItems` с `capturedAt`;
- считать Gateway единственным владельцем правила свежести цены D-14, чтобы UI
  и SEO не могли показать цену старше 45 дней.

## Совместимость и миграция

Изменение намеренно несовместимо на уровне TypeScript DTO. Все потребители в
этом репозитории обновляются атомарно. Persisted data переводится
отдельной проверяемой Payload migration с явным fallback для прежних статусов.

## Откат

Down migration возвращает прежние enum-значения по документированному fallback.
На уровне presentation contract откат выполняется только полным revert
связанного изменения;
частичное одновременное использование DTO 2.0 и 2.1 запрещено.
