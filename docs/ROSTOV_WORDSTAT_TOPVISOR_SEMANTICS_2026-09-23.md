## Итог

- 39 запросов — менее 50;
- у 59 запросов точная частота равна нулю: это не обязательно отсутствие спроса, но отдельный URL под точную формулировку обычно не оправдан;

Главный вывод: отдельные посадочные страницы следует строить не по одной частоте, а по сочетанию **спрос + реальные объекты + уникальный интент**. Рекомендуемый стартовый порог:

`seoInventoryThreshold = broad >= 100 AND activeObjects >= 5`

Для сильных микрорайонов и пригородов допустим тестовый порог `broad >= 50 AND activeObjects >= 10`, если страница получает уникальный ассортимент, текст и перелинковку.

## Что запускать в первую очередь

### P1 — основные хабы и коммерческие посадочные

1. Общегородские хабы: квартиры, новостройки/ЖК, дома, аренда квартир, вторичное жильё.
2. Подборки по типу: однокомнатные, двухкомнатные, студии, дачи, участки СНТ/ИЖС.
3. Сильные микрорайоны: Суворовский, Левенцовка, Красный Аксай, Северный, Западный, Центр.
4. Пригороды: Батайск и Аксай — отдельные городские хабы; Аксайский район — отдельный загородный кластер.
5. Административные районы: страницы квартир по Кировскому, Первомайскому, Ворошиловскому, Советскому, Ленинскому, Пролетарскому и Железнодорожному районам; страницы домов — там, где есть достаточный ассортимент.

### P2 — запускать после проверки инвентаря и выдачи

- Платовский, Вересаево, Нахичевань, Военвед, Сельмаш, Александровка, Темерник.
- Новостройки Октябрьского района: широкая частота всего 31, но точная 12 — узкий и относительно чистый интент.
- Чалтырь, Мясниковский район, запросы «под Ростовом».
- Коммерческая недвижимость: спрос есть, но его лучше собирать через категории и фильтры, а не одной общей страницей.

### Не выделять отдельным URL на первой волне

- Змиевка: 0 по квартирам и домам.
- ЖДР: 0; использовать полное название «Железнодорожный район».
- «Левенцовский», «северный жилой массив», «западный жилой массив» — слабее народных коротких форм; оставить как синонимы.
- Берберовка по квартирам, Чкаловский по новостройкам, коттеджный посёлок «под Ростовом» — только внутри более крупных кластеров.
- Запросы с broad менее 50 без достаточного количества объектов.

## Как читать цифры

- **Широкая** показывает весь хвост запросов со словами и словоформами. Она полезна для оценки размера кластера.
- **Точная** показывает спрос на близкую фиксированную формулировку. Низкая точная при высокой широкой означает, что спрос распределён по длинному хвосту.
- **0 в точной** не равен нулевому спросу по теме. Это сигнал не делать страницу вокруг одной формулировки без дополнительной проверки выдачи.
- Частотность — оценка показов, а не число людей, кликов или сделок.

## Рекомендуемая архитектура семантики

1. **Тип объекта → сделка:** купить квартиру, купить дом, купить участок, снять квартиру, коммерческая недвижимость.

3. **Подборки:** комнатность, ремонт, готовность дома, класс жилья, ИЖС/СНТ.
4. **Синонимы в нормализации:** СЖМ ↔ Северный; ЗЖМ ↔ Западный; ЖДР ↔ Железнодорожный район; Левенцовка ↔ Левенцовский.

## Ограничения и следующий замер

- Topvisor вернул актуальный снимок частотности, но динамика за 12 месяцев в этот запуск не входила.
